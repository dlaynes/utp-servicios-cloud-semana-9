# Matriz nube pública vs nube privada

| Aspecto | Nube pública | Nube privada |
|---|---|---|
| Infraestructura | Requiere planificación de red virtual, contenedores y aplicaciones | Requiere planificación y adquisición de red virtual |
| Responsable | Ingeniero de software | Ingeniería de sistemas |
| Aprovisionamiento | Más flexible y automatizable | Mayor control, pero más gestión interna |
| Escalamiento | Muy flexible durante picos de demanda | Menos flexible pero más controlado |
| Seguridad y acceso | Depende del proveedor | Mayor control interno |
| Monitoreo | Servicio externo del proveedor | Herramientas internas |
| Costo/consumo | Variable según el consumo | Más predecible |
| Caso de uso | Aplicaciones de acceso público y alta demanda | Datos internos de la universidad y sistemas sensibles |
