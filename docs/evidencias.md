# Evidencias sugeridas

1. `docker compose ps` mostrarando los 3 servicios.
2. `docker compose logs api`.
3. Navegador en `http://localhost:3000`.
4. `kubectl get pods` si usas Kubernetes.
5. `kubectl get svc` si usas Kubernetes.
6. Terminal mostrando la API en `http://localhost:8000/api/estado`.
7. Terminal mostrando `kubectl scale` y `kubectl delete pod`.
