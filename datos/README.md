La base de datos es ficticia y por simplicidad se modela con JSON en lugar de SQLite. La idea es separar los datos del frontend y de la API.

- `estudiantes.json` / listado de estudiantes ficticios.
- `cursos.json` / listado de cursos.
- `calificaciones.json` / notas asociadas a estudiantes y cursos.

Esta carpeta es el componente de datos.
