La API es el servicio HTTP. Su función central es exponer los datos académicos disponibles en la carpeta `datos`.

- Puerto interno: `8000`
- Endpoints:
  - `GET /api/estado`
  - `GET /api/salud`
  - `GET /api/estudiantes`
  - `GET /api/cursos`
  - `GET /api/calificaciones`
  - `GET /api/estadisticas`
